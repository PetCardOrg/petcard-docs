# Teste de usabilidade — respostas do formulário

Respostas brutas do formulário aplicado aos participantes do teste de usabilidade do PetCard (app do tutor e painel web do veterinário), disponibilizadas para consulta da banca do TCC.

| | |
|---|---|
| **Arquivo** | [`PetCard - Respostas do teste de usabilidade.xlsx`](PetCard%20-%20Respostas%20do%20teste%20de%20usabilidade.xlsx) (exportação do Google Forms) |
| **Onde aparece no TCC** | Apêndice — *Respostas do teste de usabilidade* |
| **Período de coleta** | 17/10/2026 a 03/11/2026 |
| **Respondentes** | 28 (21 tutores de pet, 3 veterinários/estudantes de veterinária, 4 outros) |
| **Privacidade** | Respostas anônimas; o formulário registra o consentimento de uso exclusivamente acadêmico (coluna `Consentimento`). Não há nome, e-mail ou outro identificador na planilha. |

## Estrutura da planilha

A aba `Respostas ao formulário 1` tem uma linha por respondente e as colunas:

| Bloco | Colunas |
|---|---|
| Perfil | Carimbo de data/hora, faixa etária, relação com o tema |
| App do tutor (mobile) | Facilidade de uso, adequação das funções, tarefa mais difícil (M3–M7) |
| Site do veterinário (web) | Facilidade de uso, adequação das funções, tarefa mais difícil (W1–W5) |
| Objetivos da plataforma | Centralizar o histórico clínico, promover adesão a cuidados preventivos, compartilhar o histórico com o veterinário, encontrar clínicas próximas |
| Geral | Recomendação de 0 a 10, o que mais gostou, o que atrapalhou/sugestões |
| Consentimento | Texto de aceite do participante |

As escalas de concordância vão de 1 a 5. Os blocos do site são respondidos apenas por quem usou o painel web (7 respondentes) e os do app apenas por quem usou o app.

## Código-fonte avaliado

Os sistemas testados estão nos repositórios do ecossistema, listados no [README principal](../../README.md#ecossistema-petcard): [petcard-mobile](https://github.com/PetCardOrg/petcard-mobile) (app do tutor), [petcard-web](https://github.com/PetCardOrg/petcard-web) (painel do veterinário) e [petcard-api](https://github.com/PetCardOrg/petcard-api) (backend).
